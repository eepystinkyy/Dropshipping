# Research — Cowork's working directory

Working notes, candidate briefs, supplier quotes, objection logs.

Cowork owns this directory (see `../CLAUDE.md`). Claude Code reads it but should not
edit it, to avoid two agents writing the same files.

When something here becomes a decision, promote it into `../docs/` and commit. The
commit is what makes it real.

## Expected contents

- `candidates/` — one brief per product candidate: audience, product, 3 supplier quotes
  with landed cost, unit economics output, competitor teardowns, 5 content angles
- `suppliers/` — quotes, DDP terms, HTS codes, sample notes
- `objections/` — the CS objection log, feeding product page iteration
